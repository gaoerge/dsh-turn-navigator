# Changelog

## 1.0.0

- Prepare the standard CSS-only turn-navigation plugin for public distribution.
- Preserve `@local/dsh-turn-navigator`, native navigation behavior and existing row/module identifiers.
- Manage style creation and removal together through `ctx.effect`.
- Add original SVG artwork, Chinese/English metadata, documentation, MIT license and dependency-free package checks.
- Declare DSH `0.2.1-rc.5` as the known compatibility target; no other version is claimed as verified.
- Exclude official-module backups and experimental viewport patches. No message-body virtualization changes are included.

Browser validation and screenshots for this release package remain pending.
